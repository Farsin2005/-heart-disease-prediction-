# Heart Disease Risk Prediction Web App

An end-to-end machine learning web application built to predict whether a patient is at risk of heart disease based on clinical parameters. 

## Tech Stack
* **Python**
* **Scikit-Learn** (Random Forest Classifier)
* **Streamlit** (Web framework)
